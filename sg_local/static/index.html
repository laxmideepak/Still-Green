Add a Slack workspace

The browser extension is the easy way. You can also paste the two Slack values by hand.

Use the Stillgreen browser extension

Recommended
  1. Open your workspace at app.slack.com in Chrome.
  2. In the extension, set Stillgreen address to this page's address and paste your access code.
  3. Click Capture from Slack. The workspace shows up here within a few seconds.
or paste the two values by hand

Where do I find these values?
  1. Open Slack in Chrome. Open DevTools, go to Network, filter by api, open a client.boot request and copy token from the payload. It starts with xoxc-.
  2. In DevTools, go to Application → Cookies → https://app.slack.com and copy the d cookie. It starts with xoxd-.
  3. Both values must come from the same signed-in tab. They are sent only to this Stillgreen, never to the website.
