Add a workspace

Easiest: use the Stillgreen extension's Capture from Slack button. Or open the workspace at app.slack.com and copy the two values from DevTools. They go only to this daemon.

Where do I find these?
  1. Open DevTools → Network, filter api, open a client.boot request, and copy token from the payload — it starts with xoxc-.
  2. DevTools → Application → Cookies → https://app.slack.com → copy the d cookie, which starts with xoxd-.
  3. Both values must come from the same signed-in browser session.
