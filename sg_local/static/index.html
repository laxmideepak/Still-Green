Use the Stillgreen browser extension

  1. Open your workspace at app.slack.com in the same browser.

or add it by hand
Where do I find these values?
  1. In Slack in the browser, open DevTools → Network, filter api, open a client.boot request and copy token from the payload. It starts with xoxc-.
  2. DevTools → Application → Cookies → https://app.slack.com → copy the d cookie. It starts with xoxd-.
  3. Both values must come from the same signed-in session. They are sent only to this daemon.
